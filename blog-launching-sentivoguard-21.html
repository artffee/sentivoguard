Launching SentivoGuard 2.1 — real-time protection, encrypted vault, AV-grade detection

SentivoGuard 2.1 is the first public release. 14 security tools, one installer, $49/year. Free tier requires no key.

What it is

SentivoGuard is a Windows desktop suite that consolidates the security stack most people half-cobble-together: VPN, password manager, system cleaner, AI assistant, network monitor, firewall manager, ad blocker, encrypted chat, file transfer, DNS control, hotspot sharing, driver updater, Defender enhancement, and a 7-engine supply-chain scanner.

Buying those separately costs around $166/year (NordVPN $60 + Malwarebytes $40 + 1Password $36 + CCleaner $30). SentivoGuard Plus is $49/year.

What's actually working today

2.1 ships with seven major components fully real, not mocked:

  • Disk Scan — antivirus-style streaming scan. 16,000 files in 7.6 seconds. Eight threat categories (credential theft, network exfil, code execution, obfuscation, persistence, mining, ransomware, Windows-shell droppers) plus filename and location heuristics.
  • Quarantine — reversible move-to-safe-storage with SHA-256 integrity checks. System-path guards (won't touch C:\Windows\System32). Restore returns the byte-for-byte original or refuses on hash mismatch.
  • SentivoVault — AES-256-GCM password manager built on Web Crypto. PBKDF2 with 200k iterations. Master-password gate, 10-minute auto-lock. Wrong password is rejected by the GCM auth tag, not a soft check.
  • VirusTotal integration — every finding has a one-click hash lookup against 70+ commercial AV engines via the v3 API. Free-tier rate-limited (4/min, 500/day) with a 24-hour disk cache.
  • Real-time watcher — fs.watch daemon on Downloads, Desktop, the Temp directories, and AppData/Roaming. Findings stream to the browser via Server-Sent Events. New file lands → activity feed updates instantly.
  • SentivoWatch — per-process network monitor backed by PowerShell Get-NetTCPConnection. Real connections, real PIDs, real process names — not a static demo.
  • SentivoClean — real cache enumeration plus safe deletion against a strict allowlist (Temp, Chrome/Edge/Firefox cache, Prefetch, thumbs, recycle bin, DNS flush). Won't touch user documents.

What's still mocked

Being honest: the VPN tunnel, ad blocker, firewall manager, and Defender wrapper still ship as polished UI without real OS integration. Same for the chat, transfer, hotspot, and driver updater. Those need WireGuard kernel drivers, hosts-file modification, Windows Firewall API binding, and the like — each is its own project.

Every mocked tool says MOCK MODE in the badge so you always know which is which. We'll convert them one at a time.

Pricing

  • Free — Disk Scan, Quarantine, Instinct (npm + folder), basic SentivoClean. 1 device.
  • Standard ($29/yr) — adds real-time protection, VPN (10 servers), SentivoBlock, SentivoWatch, SentivoDefend. 3 devices.
  • Plus ($49/yr) — adds Nova AI (1M tokens/mo), SentivoVault, SentivoChat, SentivoDNS, all VPN servers. 5 devices.
  • Ultimate ($99/yr or $179 lifetime) — adds Transfer, Hotspot, Drivers. Nova AI (5M tokens/mo). Unlimited devices.

Install

Grab the Windows installer — 76 MB, NSIS, unsigned (so Windows SmartScreen will warn — click "More info" → "Run anyway"). Production releases will be EV code-signed. macOS and Linux: clone the repo and run npm install && npm run build:mac.

Free tier doesn't require a license key. Plus / Ultimate keys arrive by email after Stripe checkout. Paste them into Settings → License key and you're activated.

Source available

The full source is on GitHub. License is proprietary (you can read and personally build, but not redistribute or resell) but the source-visible release means anyone can verify the privacy claims: that disk scanning runs on-device, that Nova AI only sends conversation text to Anthropic's API, that the vault is encrypted before it touches localStorage. No black boxes.

For a deep dive on how the disk scanner is built, read How we built a real-time disk scanner in Node.js.
