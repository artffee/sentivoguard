Real-time protection

Detection that doesn't sleep.

  • 8 threat categories: credential theft, network exfil, code execution, obfuscation, persistence, mining, ransomware, dropper patterns
  • Filename heuristics: typo-squatted system processes, double extensions (invoice.pdf.exe), phishing-themed names
  • Location heuristics: executables in Temp, AppData/Roaming outside known-vendor folders, rare extensions in Downloads

Stripe checkout integration is wired but inactive on this preview. To test the activation flow, mint a key locally:

SG_LICENSE_SECRET=your-secret \

Paste the resulting JWT into Settings → License key in the app to unlock Plus features.
